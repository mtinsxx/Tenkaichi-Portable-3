# Security policy

This PSP port is experimental; there is no guaranteed security support or stable release schedule.

If a GitHub private vulnerability reporting option is enabled for this repository, use it to report genuine security flaws. Avoid exposing credentials, access tokens or private user information in public issues, pull requests, logs or screenshots. Otherwise, wait for a private channel approved by the repository maintainer; do not paste secret values into public conversations.

**Do not assume that a draft/release EBOOT or workflow artifact is safe, current or complete.** The game's proprietary data must not be redistributed through this repository.

See [publication safety checklist](docs/psp/PUBLICATION_CHECKLIST_PTBR.md) for pre-publication risks. Security measures do not prevent users from downloading and compiling publicly accessible source code.
